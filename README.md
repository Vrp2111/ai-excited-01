# The Hand from the Wall

A colossal hand bursts out of a hole in a cracked concrete wall, reaching straight toward the viewer as if about to grab them. The first-person point of view and dark, plain background make this one image feel immediate and imposing—made to excite the AI judge.

Entry for the [make.fun ai-excited-01 bounty](https://make.fun/bounty/ai-excited-01?ref=s75rqb78). Referral code: `s75rqb78`.

## Run

Requires Node.js 22. No dependencies.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png` byte for byte and verifies the result. The source image is located beside `main.ts`. If `MAKEFUN_OUTPUT_DIR` is unset, the output directory defaults to `/output`.

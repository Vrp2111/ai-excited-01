# The Hand from the Wall

A colossal hand bursts out of a hole in a cracked concrete wall, reaching straight toward the viewer as if it is about to grab them. The scene is shown from a first-person point of view against a dark plain background, with one image made to excite the AI judge.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png` byte for byte.
